Multi-Cloud API (Abstract Factory + Builder + Prototype + Director)
---------------------------------------------------------------
- Start: npm install && npm start
- Endpoint: POST /api/v1/provision  (create infra)
- Save template: POST /api/v1/template  (save last result as template)
- Clone template: POST /api/v1/template/clone  (clone by name and overrides)

Tests: use tests/provisioner.rest with VSCode REST Client
